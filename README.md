# Andy Lee — personal website

Static GitHub Pages copy of https://andyslee.lovable.app/, captured November 16, 2026.

## Files

- `index.html`: the reference site’s portfolio text and LinkedIn links.
- `style.css`: matching serif typography, spacing, responsive CV layout and automatic dark mode.

No build step or JavaScript is required. GitHub Pages can serve the repository root. Google Fonts supplies Source Serif 4; system serif fonts are the fallback.

The Lovable editor badge and framework hydration scripts are not included: they are hosting/editor scaffolding, not portfolio functionality. The source site's `noindex,nofollow` setting is preserved. This is not access control; the repository and any published Pages site remain public.

Do not merge the copy branch until publication is approved. This change does not change Pages configuration.
