This page has the things I've built, a short version of where I'm from, and where I've worked. If you'd like to talk about any of it, LinkedIn is the easiest way to reach me.

things I've built

Manual operations process (at Uber)
I built an AI workflow that reduced the time needed for a manual operations process from three weeks to about 15 minutes, with a person reviewing the results. It has been adopted by three teams.
Andy OS (personal project)
I built a context and memory layer for AI agents, with controls over what each agent can access. It is still in development.
AI Mission Control (personal project)
A local dashboard that shows what my coding agents have done. It also has an optional supervised workflow for assigning tasks and reviewing follow-ups. It is still in development.
AI Film Studio (personal project)
A local workspace for planning short AI films, comparing generated images and clips, and assembling a rough cut. Image and video generation still involve manual steps and imports.
